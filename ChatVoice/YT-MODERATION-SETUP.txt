YOUTUBE MODERATION  -  delete rule-breaking messages and time out repeat offenders
Reading chat needs no login. Only deleting does. ChatVoice signs in once with a Google account.

WHO SIGNS IN
Use the channel account, or better a separate "ChatVoice Bot" Google account that you add as a moderator in
YouTube Studio (Settings > Community). The signed-in account must be the owner or a moderator, or YouTube refuses.

ONE-TIME GOOGLE SETUP  (console.cloud.google.com, free, no card)
1. Create a project (any name).
2. APIs & Services > Library > "YouTube Data API v3" > Enable.
3. APIs & Services > OAuth consent screen: User type External, fill the app name and your email. On the Audience /
   Test users page add the Google accounts that will sign in (the bot account, friends' accounts).
   Publishing status: while it says "Testing", Google may expire the sign-in after about 7 days. Pressing
   "Publish app" avoids that, but the app stays "unverified": a warning screen appears and about 100 users are allowed.
4. Credentials > Create credentials > OAuth client ID > Application type: Desktop app. Copy the Client ID and secret.
5. In ChatVoice > YouTube mod: paste both, click "Sign in with Google", finish in the browser.
   (Alternative: put them in a file google_client.json in %APPDATA%\ChatVoice:  {"client_id":"...","client_secret":"..."} )

USE IT
- Start in TEST MODE (the default). The feed shows "TEST MODE: would delete ..." so you can see it behave.
- Then untick TEST MODE. Moderators and the streamer are never touched.
- Rules: blocked words (Moderation page), links, spam/repeats. After N deletions in 10 minutes a viewer is timed out.

QUOTA (important)
Google gives 10,000 units a day to the whole Google project. Each delete or time-out costs 50, so about 200 actions a
day for EVERYONE using your project. Reading chat via this app costs nothing. ChatVoice has a daily action limit
(default 60) per streamer. If friends share one Google project, lower it or let each friend create their own project.

HONEST LIMITS
- This was tested against a simulated YouTube, not the real one. Test mode first, on a quiet stream.
- It finds the message to delete by matching the viewer and the text in the last messages. If YouTube's wording differs
  (for example emoji), it may report "could not find the message" rather than delete the wrong one.
- The Google sign-in token is stored as a plain file in %APPDATA%\ChatVoice. Anyone with access to your Windows
  account could use it. Sign out in the app to delete it.
