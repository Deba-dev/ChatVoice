FROM PROJECT FOLDER TO ChatVoice-Setup.exe  -  free, using GitHub (about 15 minutes)

You need: a free GitHub account (github.com). You do NOT need Python or any tool on your PC.

A. PUT THE PROJECT ON GITHUB  (easiest way: GitHub Desktop)
1. Unzip ChatVoice-Project.zip. You get a folder named ChatVoice.
2. Install GitHub Desktop (desktop.github.com) and sign in.
3. File > Add local repository > choose the ChatVoice folder. If it says "not a repository", click "create a repository".
4. Click "Commit to main", then "Publish repository". Untick "Keep this code private" (public repositories get unlimited
   free build minutes; private ones get a monthly allowance). Publish.
   Nothing secret is inside the project: your Discord / Google / Razorpay keys are never in these files.

   Without GitHub Desktop: on github.com click New repository (public), then "uploading an existing file", drag the contents
   of the ChatVoice folder in. The hidden folder .github may be skipped: then click Add file > Create new file, type the name
   .github/workflows/build.yml  and paste the contents of that file from the zip.

B. BUILD
1. On the repository page open the "Actions" tab. If asked, click "I understand my workflows, go ahead and enable them".
2. Left side: "Build ChatVoice" > "Run workflow" (green button) > "Run workflow".
3. Wait 5 to 10 minutes. A green tick means success. A red cross: open it, click the failed step, and send me the red text.

C. DOWNLOAD
1. Open the finished run. At the bottom, under "Artifacts", click "ChatVoice-Setup". A zip downloads.
2. Unzip it: inside is ChatVoice-Setup.exe. That is the installer you give to friends.
3. Run it. Windows may show "Windows protected your PC": click More info > Run anyway (it is unsigned; a signing certificate costs money).

D. NEXT VERSIONS  (full steps in UPDATING.txt)
Change the files, commit and push in GitHub Desktop, then run the workflow again (step B). To get a permanent download page,
create a tag like v0.4 (GitHub Desktop: History > right-click a commit > Create tag) and push it; the workflow also runs on tags.

TROUBLESHOOTING
- "Actions" tab missing: Settings > Actions > General > Allow all actions.
- Antivirus flags the installer: this happens with apps made this way. Report it as a false alarm to the antivirus / Microsoft.
- The workflow was written without being run on GitHub (I cannot do that here). If a step fails, the red text tells me what to fix.
